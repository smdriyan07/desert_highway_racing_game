# Desert Highway

A colorful endless-driving arcade game built with Python and Pygame. Dodge
desert traffic, collect gold coins, grab nitro boosts and crash shields, and
try to beat your best score.

The latest arcade edition includes procedurally generated sound effects,
animated particles, speed effects, and a sound toggle. Earlier versions are
also included to show how the game developed.

## Features

- Endless traffic-dodging gameplay
- Coins and power-ups, including nitro boosts and crash shields
- Animated particles, speed effects, and a score display
- Procedurally generated sound effects, with an in-game sound toggle
- Several earlier versions preserved for comparison

## How to play

GitHub displays the project files but does not run Python games inside the
repository page. To play, download the repository using **Code → Download ZIP**
and extract it, or clone it with Git. Then install Python 3 and Pygame:

```powershell
py -m pip install -r requirements.txt
```

Run the latest version from the project folder:

```powershell
py game01.py
```

Use **A/D** or the **left/right arrow keys** to steer. Press **S**, **Enter**,
or **Space** to start or restart. Press **M** on the menu or game-over screen
to toggle sound. Press **Esc** to quit.
